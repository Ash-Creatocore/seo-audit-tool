    What this tool deliberately does not show

    • Backlinks, domain authority, referring domains — these require a paid link index (Semrush, Ahrefs, Moz). Rather than display an estimate, this tool omits them.
    • Organic traffic and search volume — require paid clickstream/keyword data. Omitted for the same reason.
    • Competitor domains, Google Business Profile, reviews — require third-party data sources not integrated here.
    • Indexing status is a site: query heuristic; rank tracking is bounded by the Custom Search API's result cap; rank history starts from your first check on this server.
